# Brennan Vehicle Sim

MATLAB and Simulink tools for Formula SAE vehicle dynamics, tire modeling,
acceleration simulation, lap-sim result visualization, and logged data analysis.

The repository is organized around quick engineering scripts rather than a
single packaged application. Most workflows are run directly from MATLAB.

## Repository Layout

- `VehicleBalance_MF12.m`, `VehicleBalance_MF13.m`, `VehicleBalance_MF14.m` -
  steady-state cornering balance models for different vehicle generations.
- `Accel_Simulator.m` - 75 m acceleration event simulation with gear shifting,
  traction limits, aero drag/downforce, rolling resistance, and launch behavior.
- `Accel_Sim_AeroSweep.m`, `Accel_Simulator_DRS_Comparison.m`,
  `DRS_visualization.m` - acceleration and DRS/aero comparison studies.
- `roll_stiffness_MF12.m`, `roll_stiffness_MF13.m`,
  `U_bar_optimize.m`, `chassis_torsional_rigidity_impact.m` - roll stiffness,
  anti-roll bar, and chassis stiffness calculations.
- `Suspension_Forces_MF13.m`, `CW_MF13FrontSpindleBearingForces.m`,
  `BK_WheelLoads.m` - suspension, bearing, and wheel-load calculations.
- `Tire Modeling/` - tire test data, Pacejka tire model functions, run plots,
  and TTC resources.
- `Data Visualiztion/` - scripts and data for visualizing logged vehicle data.
- `Lap Sim Visualization/` - lap-sim sensitivity plots for aero, power, and
  mass changes.
- `Understeer Gradient/` - constant-radius understeer gradient data and plots.
- `VDBS/` - MATLAB Virtual Vehicle / Simulink project files, generated
  configuration data, vehicle dictionaries, and Simulink models.

## Main MATLAB Workflows

### Vehicle Balance

Run one of the vehicle balance scripts from the repository root:

```matlab
VehicleBalance_MF13
```

These scripts estimate steady-state cornering balance using wheel loads,
load transfer, aero distribution, camber, toe/Ackermann effects, Pacejka lateral
tire force, and aligning moment calculations.

`VehicleBalance_MF13.m` adds the tire modeling folder to the MATLAB path:

```matlab
addpath(genpath("Tire Modeling"))
```

If running other scripts directly, add the relevant folders to the path first if
MATLAB cannot find helper functions.

### Acceleration Simulation

Run:

```matlab
Accel_Simulator
```

The script models a 75 m acceleration event and outputs plots for tractive
force, traction limit, RPM, shift points, velocity, and acceleration.

### Tire Modeling

Core tire helper functions live in `Tire Modeling/Function Files/`:

- `pacejka.m` - lateral force model.
- `pacejkaMZ.m` - aligning moment model.
- `findSlip.m` - bisection solver for axle slip angle.

The tire modeling folders also contain TTC raw/run data, processed exports, and
plotting scripts for specific tire runs.

### Data Visualization

Logged data scripts live in `Data Visualiztion/`. Many of these scripts expect
the matching `.mat` or `.csv` files under `Data Visualiztion/Data Files/` or
`CSV Data/`.

## Requirements

- MATLAB.
- Simulink for files and workflows under `VDBS/`.
- Git LFS for large binary data and Simulink assets.

After cloning, make sure Git LFS files are present:

```bash
git lfs pull
```

## Data and Large Files

Large engineering artifacts are tracked with Git LFS, including:

- `.mat`, `.csv`, `.fig`
- `.slx`, `.sldd`
- `.zip`, `.xlsx`, `.xls`, `.pdf`
- image and document files

The largest assets are tire test archives, MATLAB data files, logger exports,
and Simulink model/dictionary files.

## Notes

- Units vary by script. Several vehicle balance calculations use imperial units
  such as pounds and inches, while acceleration simulations use SI units. Check
  the setup section at the top of each script before changing parameters.
- Some directory names contain spaces, and a few retain historical spelling such
  as `Data Visualiztion` and `Data Visulization`.
- `VDBS/VirtualVehicle/VirtualVehicle/System/MF13/MF13.m` is autogenerated by
  MATLAB Virtual Vehicle tooling and contains machine-specific original project
  paths.
